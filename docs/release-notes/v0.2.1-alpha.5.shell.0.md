# dsh-desktop v0.2.1-alpha.5.shell.0

> 未发布候选。公开下载仍以官网及实际 GitHub Release 为准。

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-alpha.5`。

## 本次更新

- **内核升级**：升级到官方已发布的 alpha.5 预览版，同步内核同族直接依赖与完整锁文件闭包。
  上游包含已打开会话的 `/` 技能列表随插件启停刷新、批量新建/恢复终端时减少重复查询、
  Windows/Linux 右侧栏收起时输入框 Page Up 不再左移界面、PTC 指引与模型身份说明统一，
  并新增 `conversation.input.model.label` Slot。
- **供应链豁免按真实闭包补齐**：新内核首次引入的传递依赖同样处于 24 小时发布窗口内；
  `sync-release-age-excludes.mjs` 现按新锁文件实际解析结果补齐 `minimumReleaseAgeExclude`，
  纯函数回归覆盖 peer 后缀解析，避免把 peer 依赖误写成包名或让冻结安装反复失败。
- **桌面登录兼容**：账户补丁随精确版本迁移到 alpha.5，继续只在官方桌面桥具备
  `dshOnboarding.hasApiKey` 能力时走内嵌登录；Electron 拒绝预开空白窗口时，
  仍把实际授权 URL 一次性交给系统浏览器，不放开导航、Node 权限或外链协议。
- **垃圾桶兼容**：alpha.3 → alpha.5 的上游会话控制器与工作区客户端逐字节一致，
  补丁锚点已重新核对，版本保护更新为 alpha.5；运行中、排队中、跨客户端所有权、
  维护中及子会话仍拒绝删除。
- **飞书凭据边界**：ACP 组合仍加载 Models 已保存的模型凭据，
  headless 专用的凭据覆盖不会套用到机器人连接；飞书 App Secret 与模型 API Key 保持分离。

## 验证

- 官方 npm registry 与 GitHub Release 均确认 alpha.5；
- `pnpm -C manifest/harness install --frozen-lockfile` 与 `pnpm run bootstrap`（含闭包 peer 审计）退出 0；
- 内核兼容单测覆盖登录补丁、垃圾桶生命周期、ACP 凭据组合与补丁迁移；
- `pnpm verify`、`pnpm security:audit` 回执见 `docs/plans/2026-10-17-self-evolution.md`。
- 本候选尚未执行真实飞书往返、打包安装或发布；对应门禁在后续任务中完成。

## English Summary

- Upgrades the bundled Harness to the published 0.2.1-alpha.5 preview and resyncs the exact closure lockfile.
- Extends the release-age exemptions from the real lockfile resolution, with a pure regression test
  that keeps peer-suffixed keys from becoming bogus package pins.
- Carries the reviewed account patch to alpha.5, preserving system-browser authorization and the
  official-desktop-only login capability check.
- Verifies the session-trash lifecycle anchors against the new upstream bundles before updating the
  version guard; busy, owned, maintenance and child sessions remain protected.
- Keeps the ACP saved-credential composition and the separation between Feishu secrets and model API keys.
- Live Feishu delivery, packaged installation and the release itself remain outside this candidate's validation.
