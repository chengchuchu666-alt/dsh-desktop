# dsh-desktop v0.2.1-alpha.2.shell.3

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-alpha.2`（未变，壳修订 +1）。

## 本次更新

- **运行时与安全维护**：Electron 44.7.0、YAML 2.9.1；捆绑闭包更新 proxy-addr 2.0.8、
  compression 1.8.2 与 MCP SDK 1.31.0。显式保留原有可选 SDK 功能，不用移除包来消除告警，
  不升级 Harness 内核或无关 Web 栈。
- **打包依赖审查**：electron-builder 26.17.0，保留既有 macOS 工具的 plist 3.1.1 / xmldom
  0.9.12，避免依赖 PR 的额外降级；Node 类型继续与 Node 24 运行时一致，不采用 Node 26 类型。
- **官网与飞书指南**：中英首页新增独立飞书连接流程，说明工作区、精简消息、卡片、连接意图、
  安全模式与组织权限。FAQ 区分机器人 Secret、模型 Key 和 CLI OAuth，补充 Keychain 与 Windows
  profile 写入权限排查；不把最初白屏问题冒称为已修复。
- **官网同步可靠性**：生成文件 push 冲突时基于最新主干重新生成并限次重试；只变更新日志时
  也会提交。官网日志以已发布 tag 为上界，不提前展示未来版本草稿。
- **测试收尾可靠性**：cc-connect 文件附件 CUJ 等到最终回复且任务锁释放后才结束，
  修复后台持久化与临时目录清理的竞争；不改变 Agent 或飞书生产行为。
