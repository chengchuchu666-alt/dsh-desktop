# dsh-desktop v0.2.1-alpha.2.shell.4

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-alpha.2`（未变，壳修订 +1）。

## 本次更新

- **关闭即退出**：关闭主窗口现在会退出整个应用，停止 Harness、飞书连接和局域网服务，
  不再留在后台。最小化/隐藏启动后仍可用快捷键或托盘唤回；关闭飞书管理小窗口只关闭界面。
- **退出收尾可靠性**：修复连接还在启动时退出会留下 Sidecar 的边界；独立服务并行停止，
  单项失败不跳过其余清理，重复退出请求不会抢先绕过清理。连接意图与自动连接选择保留。
- **macOS 飞书不再访问钥匙串**：新 Secret 保存到主进程管理的本机受限文件（权限 `0600`），
  保存、读取及自动连接都不调用系统安全存储。旧加密 Secret 保留但不后台解密，
  设置页提示重新填写一次，保存成功后才替换；不再每次更新反复请求钥匙串访问。
- **Windows 安装精简与计时**：补删不参与运行的 `.d.mts` / `.d.cts` 声明文件，维护候选本地闭包
  减少1464个文件（约7.7 MB）；保留可执行文件、原生模块、资源及许可证。
  同一 Windows runner 三轮安装中位数165.7→157.6秒，改善约4.9%；这是发布前维护候选的
  对照结果，不承诺所有电脑同样提速，也不把累计安装阶段冒称纯解压时间。
- **安全边界**：macOS 受限文件是明文，不是加密保险箱；同用户程序、管理员和可读取备份者
  仍可能访问。Windows 保留原 DPAPI 策略，Linux 保留原存储策略。不改系统钥匙串、Cookie
  或签名策略，不加入 `use-mock-keychain`。macOS 分发仍为 ad-hoc 签名。

## English Summary

- Closing the main window now exits the application and stops its owned services. Minimize/start-hidden
  activation remains supported; closing the Feishu manager alone does not close a saved connection.
- Terminal shutdown preempts pending connection startup and attempts every independent service stop;
  repeated quit requests cannot bypass cleanup. Saved connection intent is preserved.
- macOS Feishu Secrets use owner-restricted plaintext files instead of Keychain access. Legacy encrypted
  Secrets are retained without background decryption and require one explicit re-entry. Windows DPAPI
  and Linux policies remain unchanged; no mock-keychain, cookie, or signing bypass is introduced.
- Removes modern declaration files from the bundled runtime while preserving executable and native
  resources. Three alternating pre-release Windows trials improved median installation time by 4.9%
  on that runner only; this is not a speed guarantee for every PC.
- Keeps Harness 0.2.1-alpha.2 and the cc-connect pin unchanged. Fresh versioned packages and all release
  gates are required, with isolated credentials, verified mirrors and published-only website changelogs.
