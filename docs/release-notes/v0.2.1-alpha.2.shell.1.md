# dsh-desktop v0.2.1-alpha.2.shell.1

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-alpha.2`（未变，壳修订 +1）。

## 本次更新

- **垃圾桶与侧栏同步**：删除、还原和取消归档后无需重启；活动任务、驻留子任务、身份冲突及其他进程持有的会话会被安全拒绝，不强停或覆盖。
- **完整飞书应用管理**：设置和原生菜单打开同一独立窗口；默认扫码创建，支持取消、过期重试、多份本地应用、编辑、开启、持久关闭和确认移除。扫码保存不隐式开启或切换，关闭窗口不关闭连接。
- **消息降噪与卡片**：默认精简 + 3 秒预览；可选完整/精简/静默、流式预览、经典/富卡片和进度样式。修复 ACP 思考被重复映射成正文的问题；旧配置和凭据无损迁移。
- **可靠状态与安全边界**：捆绑 cc-connect 提供真实长连接健康信号，分别显示服务启动、飞书通道在线和 DSH 实际任务成功；缺模型 key 指向 Models。Secret 不回读、不进入 TOML/日志；Safe Mode 暂停和持久关闭保持独立。

- Refreshes the sidebar after trash deletion, restoration and unarchiving, while protecting active turns, child sessions, identity conflicts and external writer leases.
- Adds a unified Feishu application manager with QR cancellation/expiry/retry, local app management and explicit persistent connection controls.
