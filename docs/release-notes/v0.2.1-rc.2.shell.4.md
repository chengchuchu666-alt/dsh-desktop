# dsh-desktop v0.2.1-rc.2.shell.4

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` 0.2.1-rc.2（未变，壳修订 3 → 4）。

## 本次更新

- **桌面工具面板点空白关闭**：面板打开后点击面板外任意位置即收起；触发按钮的开关与拖动语义不变（#123）。
- **扩展动作失败不再静默**：局域网配对、安全模式、重启 Harness、打开日志、导出诊断、检查更新等操作失败时，面板底部给出「操作未完成：动作名」提示，抛出的异常同样会被捕获（#125）。
- **飞书未选工作区有字段级提示**：扫码创建或保存时，空工作区直接在输入框下方报错、`aria-invalid` 生效并聚焦到该字段，不再只写页面底部；设置页的工作区行同步显示同一错误（#124）。
- **工作区选择结果可判别**：「取消」保持静默，「目录不可用」明确提示，不再都表现为没反应（#126）。
- **托盘/菜单失败有系统通知**：重启 Harness、局域网配对、打开链接等失败时弹出系统通知并写日志，不再只留在控制台（#127）。
- **统一失败反馈约定**：每个扩展界面各有一条可见的失败通道，渲染在触发动作附近，见 ADR 0042（#128）。

## 验证

- `pnpm run verify` 通过：498 个单测全绿，覆盖率、运行时边界、站点守卫与构建均通过。
- 新增回归覆盖：面板点外关闭与失败状态、管理窗口字段级工作区错误、原生选择器可判别契约、preload 返回类型。
- 打包冒烟、打包 E2E 与四端视觉门禁随本次发布 CI 执行；本次不涉及内核升级。
- 已知边界：系统通知属尽力而为，通知中心禁用时仍以日志为准；真实飞书与托盘视觉效果由人工验收。

## English Summary

- The desktop-tools panel now closes on an outside pointerdown; the trigger toggle and drag behaviour are unchanged (#123).
- Every panel action reports failures — non-true results and thrown errors — in a single alert status line (#125).
- The Feishu manager refuses an empty workspace before IPC, with a field-level error, `aria-invalid` and focus; the settings form mirrors the same error (#124).
- The native workspace picker returns a discriminated result: cancel stays silent, an unusable directory is explained (#126).
- Menu/tray failures raise a native notification plus a log line instead of dying in the console (#127).
- ADR 0042 records the per-surface failure contract (#128).
