# dsh-desktop v0.2.1-alpha.3.shell.0

> 未发布候选。公开下载仍以官网及实际 GitHub Release 为准。

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-alpha.3`。

## 本次更新

- **内核升级**：升级到官方已发布的 alpha.3，同步依赖闭包与兼容补丁，不替换已发布的 shell.4。
- **桌面登录兼容**：适配新版登录预开窗口流程，继续把实际授权页面交给系统浏览器，
  不放开桌面窗口的导航、Node 权限或外链协议限制。
- **垃圾桶兼容**：适配新内核会话创建/串行化入口，保留运行中、排队中、跨客户端所有权与子会话保护。
- **飞书凭据边界**：核对 ACP 仍加载 Models 已保存的模型凭据，不将 headless 专用凭据策略套到机器人连接。
  飞书 App Secret 与模型 API Key 仍分离，不新增凭据导出或系统钥匙串访问。
