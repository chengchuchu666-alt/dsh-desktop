# dsh-desktop v0.2.1-rc.1.shell.0

> 发布说明随 tag 固定；公开下载与校验以实际 Release 和官网为准。

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-rc.1`。

## 本次更新

- **内核升级**：把内置 Harness 从 alpha.5 升到上游 `next` 通道的 `0.2.1-rc.1`，同步 32 个
  内核同族直接依赖、锁文件与 `minimumReleaseAgeExclude`。上游目前只发布了 npm 包
  （dist-tag `next`），尚未发布对应的 GitHub Release 或变更说明，因此本节不引用未公开的发布文案。
- **闭包差异**：按 registry 元数据逐包比对，297 个内核包全部只有版本字符串一类的小幅缩减
  （每个包 −100～−500 字节，来自 `0.2.1-alpha.5` → `0.2.1-rc.1` 的替换），没有新增或移除依赖；
  壳直接打补丁或依赖契约的三个包中，`dsh-api-session-controller` 与 `dsh-client-ui-workspace`
  逐字节一致，`dsh-client-ui-settings-account` 仅两处版本字符串变化，ACP/headless 的
  `cordis.patch.yml` 组合未变。
- **插件框架转正**：内核声明的 cordis 家族在同一批次由 `-alpha.2` 预发布转为稳定版
  （`@deepseek-ai/cordis` 4.0.5、`cordis-plugin-include` 1.0.10、`cordis-plugin-loader` 1.0.6、
  `cordis-plugin-timer` 1.1.7，以及 `cosmokit`/`schemastery` 同线更新），稳定版发布时间早于
  rc.1，属于内核自身声明的范围解析结果，不是本壳额外引入的依赖。
- **账户登录兼容**：账户补丁随精确版本迁移到 rc.1，补丁内容不变，继续只在官方桌面桥具备
  `dshOnboarding.hasApiKey` 能力时走内嵌登录；Electron 拒绝预开空白窗口时仍把实际授权 URL
  一次性交给系统浏览器，不放开导航、Node 权限或外链协议。
- **垃圾桶兼容**：会话控制器与工作区客户端与 alpha.5 逐字节一致，补丁锚点重新核对后版本保护
  更新为 rc.1；运行中、排队中、跨客户端所有权、维护中及子会话仍拒绝删除。
- **构建可复现性**：`pnpm run bootstrap` 现在固定使用仓库锁定的 pnpm 10.33.2 生成/校验锁文件，
  并显式请求 hoisted 布局，不再依赖外层 pnpm 注入的环境；此前用 pnpm 11 写出的紧凑
  `patchedDependencies` 形式会被 10.33.2 判为配置不匹配，导致 bootstrap 在
  `ERR_PNPM_LOCKFILE_CONFIG_MISMATCH` 处中止。
- **飞书快捷控制**：浮窗「连接」分组继续分开显示当前应用、桌面进程、飞书通道与 DSH 任务，
  并提供显式开启、关闭、重连；打开或轮询只读，不隐式连接、不发消息、不调用模型。

## English Summary

- Upgrades the bundled Harness from alpha.5 to the published `next` prerelease `0.2.1-rc.1`, resyncing the
  32 kernel-family peers, the lockfile and the release-age exemptions. Upstream has published npm artifacts
  only (dist-tag `next`), with no GitHub Release or changelog yet, so nothing unpublished is quoted here.
- Registry metadata shows all 297 kernel packages differ only by small version-string reductions
  (−100 to −500 bytes each); two of the three packages the shell patches or depends on are byte-identical,
  the account bundle changes only in two version literals, and the ACP/headless compositions are unchanged.
- The cordis framework the kernel declares moved from `-alpha.2` builds to stable releases in the same
  window (before rc.1), which is the kernel's own range resolution rather than shell-added churn.
- Carries the reviewed account patch and the session-trash version guard to rc.1 unchanged in behaviour,
  and makes the closure install reproducible: the pinned pnpm 10.33.2 writes/validates the lockfile and the
  hoisted layout is requested explicitly instead of inherited from the caller's environment.
- Verified by 28 kernel assertions, both packaged smokes, the packaged E2E set, repeated Feishu cases,
  market offline/real, packaged LAN pairing, `codesign --deep --strict`, 438 unit tests plus ACP and audit.
