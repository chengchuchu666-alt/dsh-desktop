# dsh-desktop v0.2.1-rc.2.shell.3

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-rc.2`（未变，只升壳修订到 `.shell.3`）。

## 本次更新

- **Electron 运行时升级到 44.9.1**：主进程随之到 **Chromium 152.0.7977.167 / Node 24.22.0**（与内置 Harness 的
  Node 24.21.0 同一条 24 线），用于收上游的安全与稳定性修复。壳的功能、界面与数据目录不变，安装包可直接覆盖升级。
- **测试工具链到 Playwright 1.64.1**：端到端与打包回归与最新驱动保持一致，本版仍跑通 24 项打包回归与四端视觉门禁。
- **边界说明**：内核仍是 `0.2.1-rc.2`，签名/公证边界与上一版一致；桌面工具面板的 Star 入口只打开仓库页面
  （带 `?ref=app-panel` 归因），不发送任何遥测。
