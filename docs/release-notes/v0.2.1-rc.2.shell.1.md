# dsh-desktop v0.2.1-rc.2.shell.1

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-rc.2`（未变，只升壳修订到 `.shell.1`）。

## 本次更新

- **桌面工具面板新增 Star 入口**：信息分组里多了一行「在 GitHub 上 Star」，点击会用默认浏览器打开仓库并带
  `?ref=app-panel` 归因，方便区分面板点击与官网点击。它只是一个常驻链接：不弹窗、不催促、不影响面板其它操作。
- **官网同步做了事实与文案迭代**：核查并修正了站点上的错误声明（内置运行时是 Node.js 24 而不是 22、去掉已下线的
  `npx` 校验命令、去掉未经核实的插件数量、把 CI 门禁的「真机」措辞改为四端 runner 视觉证据）；修正了中英文各自
  独立的文案副本（`data-i18n` 现在真正生效）；更新日志中英条目逐条对齐；SEO 补齐结构化数据、可抓取的版本快照、
  sitemap 日期与双语 404。这些随站点部署，无需更换安装包。
- **边界说明**：Star 入口与官网的 Star 邀请都只打开仓库页面，不发送任何遥测；内核 `0.2.1-rc.2`、签名与公证边界
  与上一版完全一致。

## 验证

- 493 项单测、LAN 配对 2/2、插件市场离线 1/1 与真实安装 2/2、打包 E2E 24 项、两项打包 smoke 全部通过。
- 面板改动由 desktop-controls 契约测试与 desktop-ui E2E（中英 × 明暗 × 宽窄）覆盖；官网侧由 site-check、
  site-ui（含文案漂移与 Star 入口守卫）与 493 项测试中的站点用例覆盖。
- 发布后由 CI 的四端视觉门禁复核 21 个打包扩展面，并同步 GitCode 镜像与官网数据。

## English Summary

- **Star entry in the desktop tools panel**: the INFO group gains a "Star on GitHub" row that opens the repository in
  the default browser with `?ref=app-panel` attribution, so panel clicks can be told apart from website ones. It is a
  persistent link only — no popup, no nagging, and it leaves the rest of the panel untouched.
- **The website shipped its own fact-check iteration alongside**: corrected claims (the bundled runtime is Node.js 24,
  not 22; the retired `npx` validation command is gone; the unverified plugin count is removed; CI gate wording no
  longer says "real machine"), the two independent copy sources were reconciled (`data-i18n` now actually applies),
  changelog entries were matched bullet for bullet across languages, and SEO gained structured data, a crawlable
  release snapshot, git-derived sitemap dates and a bilingual 404. All of it deploys with the site, no new installer
  required.
- **Boundary note**: both star entries only open the repository page and send no telemetry; the kernel stays at
  `0.2.1-rc.2` and the signing/notarization boundary is identical to the previous build.
