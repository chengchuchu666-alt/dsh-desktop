# dsh-desktop v0.2.1-rc.2.shell.2

DeepSeek Harness 社区桌面版 · 内置内核 `@deepseek-ai/dsh` `0.2.1-rc.2`（未变，只升壳修订到 `.shell.2`）。

## 本次更新

- **面板信息组进入四端视觉门禁**：桌面工具面板的「信息」组（关于 + 在 GitHub 上 Star）现在由
  macOS、Windows、Linux x64、Linux arm64 四个 runner 各产出一张截图，并由门禁强制校验；扩展面契约
  从 21 增至 22，任一平台缺少该画面即失败。这样面板里唯一的常驻产品入口不会再被静默改坏。
- **应用行为无变化**：内核仍是 `0.2.1-rc.2`，本版只推进壳修订号；Star 入口自 `.shell.1` 起已在面板中，
  本版不新增功能，安装包行为与上一版一致。
- **边界说明**：Star 入口只打开仓库页面（带 `?ref=app-panel` 归因），不发送任何遥测；签名与公证边界不变。

## 验证

- 494 项单测、LAN 配对 2/2、插件市场离线 1/1 与真实安装 2/2、打包 E2E 24 项、两项打包 smoke 全部通过。
- 面板信息组改动由 desktop-ui E2E（中英 × 明暗 × 宽窄）断言并产出截图；门禁本地预演通过
  （`verify-visual-evidence` 22 个必需面，四端在上一次验证运行中均通过）。
- 发布后由 CI 四端视觉门禁复核，并同步 GitCode 镜像与官网数据。

## English Summary

- **The panel's INFO group is now part of the four-runner visual gate**: the desktop-tools panel's INFO group
  (About + Star on GitHub) is screenshotted and asserted on macOS, Windows, Linux x64 and Linux arm64, and the surface
  contract grows from 21 to 22 — a platform that fails to render it fails the build, so the panel's only persistent
  product entry can no longer regress silently.
- **No behaviour change**: the kernel stays `0.2.1-rc.2` and only the shell revision advances; the Star entry has
  shipped since `.shell.1`, this build adds no feature and behaves exactly like the previous one.
- **Boundary note**: the star entry only opens the repository page with `?ref=app-panel` attribution and sends no
  telemetry; the signing/notarization boundary is unchanged.
