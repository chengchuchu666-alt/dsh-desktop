# dsh-desktop v0.2.1-rc.2.shell.0

DeepSeek Harness 社区桌面版 · 内置内核升级到 `@deepseek-ai/dsh` 0.2.1-rc.2（内核升级会把壳修订号重置为 0）。

## 本次更新

- **内核升级 `0.2.1-rc.1` → `0.2.1-rc.2`**：同步 32 个 `@deepseek-ai/dsh-*` peer 版本，重生成 manifest 锁定文件，
  并把发行年龄豁免重新固定到新内核（315 → 302 条，13 条保留锁定文件中的解析版本）。两处已复核的壳内补丁
  （账号授权弹窗回退、会话回收站生命周期）确认继续适用：被补丁的两个上游 bundle 在 rc.1 与 rc.2 之间
  **逐字节相同**，两个变换在新源码上仍然命中；补丁清单因此改为显式的「已复核内核」列表。
- **控制套接字路径修复（macOS）**：非 legacy 应用的 sidecar 数据目录很深，
  `…/cc-connect/applications/〈应用 ID〉/data/run/api.sock` 超过 macOS `sun_path` 上限，`bind` 失败后管理器会把
  正常工作的连接显示成「已关闭/离线」。现在给 sidecar 一个 `$TMPDIR` 下的短别名（软链到真实数据目录，零迁移），
  实测深路径 116 字符绑定失败、别名 93 字符成功，打包后日志为 `api server started socket=/var/folders/…`。
- **飞书默认改为富卡片**：新连接的卡片样式默认 `rich`、进度展示默认 `card`（老配置与显式 `legacy` 选择保持不变）。
- **Linux arm64 产物**：发布矩阵新增 `ubuntu-24.04-arm`，与 amd64 同源打包 `-arm64.deb`；资产契约从 8 个变为 10 个
  （两个 deb 各带 `.sha256` 校验文件），应用内修复链接按运行架构选择，站点文案与 ADR 0017 同步更新。
- **发版流程新增真机视觉验证门禁**：macOS / Windows / Linux x64 / Linux arm64 四个 runner 在打包 `@smoke` 跑完后
  必须证明**渲染出全部 22 个桌面扩展面**（首启与安全模式横幅、浮动飞书快捷控制及其底部菜单、飞书管理五种状态、
  消息偏好、六个设置面板、LAN 配对、回收站、恢复、加载、插件市场弹窗）；缺失即失败并列出缺哪些，截图随工件发布
  （`scripts/verify-visual-evidence.mjs`）。
- **边界说明**：所有验证都在本地或 CI 的隔离环境完成；健康检查结果只在本地脱敏展示，不会自动上传。

## 验证

- `pnpm verify`：477 项测试全部通过（含新增的视觉证据门禁用例与内核补丁复核用例）。
- 本地 E2E：LAN 配对 2/2、插件市场离线 1/1、真实市场安装 2/2；打包 smoke 与 Harness UI smoke 均通过。
- 发布 CI：4 个 runner 打包 + 跨版本升级 + 视觉证据门禁 + attestation 全部通过后才发布。
- GitCode 镜像与官网数据在发布后刷新（6 个用户可见资产匿名可下载）。

## English Summary

- **Kernel upgrade `0.2.1-rc.1` → `0.2.1-rc.2`** with all `@deepseek-ai/dsh-*` peers, a regenerated manifest lockfile and
  re-pinned release-age excludes. Both reviewed shell patches are confirmed for the new kernel: the two patched upstream
  bundles are byte-identical between the two kernels and the transforms still apply, so the patch manifest now records the
  reviewed-kernel list explicitly.
- **macOS control-socket fix**: the sidecar's per-application data directory pushed `run/api.sock` past the `sun_path`
  limit, so the manager reported a working connection as closed. The sidecar now gets a short `$TMPDIR` alias (symlink to
  the real directory, no data migration).
- **Rich Feishu cards by default** for new connections; existing and explicitly-legacy choices are untouched.
- **Linux arm64 packages** built on `ubuntu-24.04-arm`; the asset contract lists both debs with their checksums.
- **Real-machine visual verification is now a release gate**: every desktop runner must render all 22 extension surfaces of
  the packaged app, and the screenshots ship as artifacts.
