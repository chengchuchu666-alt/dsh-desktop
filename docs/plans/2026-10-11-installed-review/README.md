# shell.1 正式安装后的真实、视觉与录屏验收

用户请求：覆盖安装 `v0.2.1-alpha.2.shell.1` 到应用程序，真实验证全部功能，包含视觉与
录屏；发现问题后规划一轮迭代、修复、复验并发布新的 shell 版本。

执行流程：验收 → 证据与复现 → 原子修复 → 验证 → 全量复验 → 按需发布。
继续用户要求的实现后验证迭代，不强制 TDD。不能删减断言或把假服务、旧验收、源码包
测试当作当前正式安装的真实通过。没有实际问题时不为验收记录单独发版。

## 基线与边界

- 父分支 `codex/cc-connect-dsh-integration`，开始时 `eef62d5497225be8207a8b87876171153214ef4f`。
- 已发布 tag 固定 `da4e4744b1e80ac31121f393d9f1f60e53431df3`；子模块 `dc8132ef5f6a30056b2b69036458156edbbfb25d`。
- 被测正式应用：`/Applications/dsh-desktop.app`，不是源码 Electron 或旧 dist。
- 只替换应用 bundle，旧版备份保留；不直接手工编辑真实 home/凭据，不删除既存会话。
- 通过正常界面只操作本轮创建的明确测试对象；修改偏好先记录原值，验收后恢复。
- 真实飞书只向已授权的本人机器人会话发送带标记消息；本轮发送授权需明确确认。
- 截图/视频保存在被忽略的 `release-check/installed-shell1-review-20261011/`，目录 0700；
  不上传私人会话、Secret、token、HAR 或未脱敏 trace。可提交文档只写脱敏结论与证据位置。
- 不自动解锁电脑或操作钥匙串/系统认证对话框；缺少手机扫码、通知权限或硬件时明确记录缺口。
- 本机真实验收为 macOS；Windows/Linux 安装验证由三平台 CI 补充，不声称本机实测。

## 真实验收矩阵

每行分别记录功能结果、视觉结果、截图/视频位置、实际数据/服务、失败与未覆盖项。
视频必须人工复核关键帧及完整交互时序，文件存在不等于验收通过。

| 面 | 真实检查 |
|---|---|
| 安装/启动 | 覆盖版本正确；启动、退出、重开、单实例、窗口/托盘与原生菜单；没有重复驻留进程 |
| 主界面 | 会话、详情、输入区、滚动、弹窗；默认/800px 窄窗、浅色/深色、中英文；无裁切、遮挡、溢出、焦点丢失 |
| 实际任务/模型 | 已配置真实模型完成带标记只读任务；思考、工具与最终答复；错误状态有准确下一步，不读回 Secret |
| 会话生命周期 | 本轮真实会话置顶、归档、取消归档、垃圾桶删除/还原；侧栏与详情立即同步，双客户端/重开持久化 |
| 数据安全 | 本轮活动任务拒绝删除、恢复冲突/子会话保护；故障/竞争仅隔离自建数据验证，不伤害真实旧会话 |
| Desktop 设置 | 版本、诊断/健康、工作区、通知、快捷键、语言主题和窗口偏好；可逆设置恢复原值 |
| 运行时/恢复 | 内置运行时信息、重启、Safe Mode 进入/退出、故障反馈与恢复；破坏性故障只用独立测试 profile |
| 插件市场 | 可见列表、真实插件安装/卸载及失败重试；安装实验只用独立测试数据与可信现有探针 |
| LAN/二维码 | 网卡/地址、生成/刷新/关闭、实际本地浏览器配对；手机扫码需要人工，不把浏览器模拟等同手机实测 |
| 飞书应用管理 | 设置/菜单同一窗口、已有记录、QR 取消/过期/保存、多记录编辑/确认移除；不隐式切换或启动 |
| 飞书连接/状态 | 服务/通道/任务分层反馈；显式开启、关闭、关闭窗口、重开、启动偏好/Safe Mode；缺 key/凭据/网络错误准确 |
| 降噪/卡片 | compact/quiet/full、预览间隔、经典/富卡片及进度；实际消息数量/内容、渲染、工具调用和关闭后无新回复 |
| 诊断/更新 | 脱敏报告、版本检查/发布链接、更新状态；不能为验证而降级或绕过签名/权限保护 |

## 修复与新版本准入

发现实际产品问题后，先追加优先级、截图/视频时间点、可重复场景、验收断言和允许文件，
再逐项最小修复、单独提交/更新进度。子模块变更先推子分支，再提交父 gitlink。
完整门禁不通过或真实验收未完成时不发布；已发布 tag 不移动。新版本沿用 shell-only
release skill，最终真实安装验证不能被旧本地包/前三平台 CI 记录替代。
