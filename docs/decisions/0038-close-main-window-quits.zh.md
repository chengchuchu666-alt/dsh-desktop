# 0038：关闭主窗口即退出应用

- 日期：2026-10-14
- 状态：已接受；取代 ADR 0006 中关闭到托盘的条款。
- English：[0038](0038-close-main-window-quits.md)

用户要求关闭主窗口后不在后台运行 Agent 与消息服务。主窗口关闭因此调用既有
应用退出路径，即使辅助窗口仍打开也退出。最小化、显式的启动后隐藏偏好和
第二实例聚焦行为不变；关闭飞书管理或配对窗口不等于退出整个应用。

退出停止消息 Sidecar、Harness、局域网服务与受管 Runtime，保留保存的配置并
按既有超时完成进程清理。进行中的任务可能中断，不能让用户误以为已关闭而
继续隐蔽执行。不增加关闭到托盘开关；旧 `closeToTrayExplained` 字段兼容读取，
但不影响关闭行为。
