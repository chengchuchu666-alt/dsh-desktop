- 日期：2026-10-11
- 状态：已接受

壳此前省略 cc-connect 显示表，旧文件会继承 full 的逐条思考/工具消息及 1500ms 预览。
缺省字段现规范化为 compact、开启预览、3000ms、经典卡片与逐条进度。这是明确改变旧默认值
的迁移，不重写凭证、不要求手改 TOML；已保存的显式偏好在旧调用/二维码参数省略时仍保留。

只暴露详细度/卡片/进度枚举、预览布尔与有界整数间隔。静默不是不回复、限制能力或关闭连接：
它隐藏独立思考/工具消息，保留最终答复、错误与权限交互。全局预览表、项目显示表仍属于
固定单项目/单平台，不是自由文本配置面。后续应用管理迁移必须无损携带这些偏好。

以稍慢预览换取较少消息更新，完整模式及更快的合法间隔仍可主动选择。经典卡片和逐条进度
保持默认，避免同时引入渲染兼容变化。Secret、sender 授权、Safe Mode 和启停规则独立不变。
真实 loader/IPC/UI 回归验证配置契约；视觉效果和实际消息数量仍需受控飞书 QA。
