# 0040：应用退出抢占未完成的连接启动

- 日期：2026-10-14
- 状态：已接受；补充 ADR 0038 与 0037 的生命周期权威。
- English：[0040](0040-terminal-shutdown-preempts-start.md)

真实 Electron 用例复现了孤儿 Sidecar：普通 pause 排在等待连接就绪的 start 后，
而壳的8秒退出兜底先结束父进程。应用退出因此使用终结式 shutdown，立即停止
已拥有的进程、拒绝后续启动，并在迟到的 factory 结果开始运行前停止它。
停止去重并排空串行尾部，保留保存的连接意图；安全模式和普通重启的策略不变。

退出时独立服务并行停止并使用 allSettled，一个失败不能跳过 Web Harness 或其它
Runtime，也不能串行累加5秒宽限超过原绝对退出预算。重复退出请求等待清理完成
或兜底到期。验收检查真实 PID 消失、取消未就绪启动、清理迟到 factory 与服务
失败时仍尝试所有停止动作，而不只是窗口不可见。
