DSH Desktop 更新日志

版本号是复合形式 <dsh 内核版本>.shell.<壳修订>：内核随官方 @deepseek-ai/dsh 升级，壳修订只包含桌面壳自身的修复与功能。以下节选近期版本要点，完整说明见各版本 Release 页。

v0.2.1-alpha.2.shell.1 （内核 0.2.1-alpha.2）

  • 垃圾桶与侧栏同步：删除、还原和取消归档后无需重启；活动任务、驻留子任务、身份冲突及其他进程持有的会话会被安全拒绝，不强停或覆盖。
  • 完整飞书应用管理：设置和原生菜单打开同一独立窗口；默认扫码创建，支持取消、过期重试、多份本地应用、编辑、开启、持久关闭和确认移除。扫码保存不隐式开启或切换，关闭窗口不关闭连接。
  • 消息降噪与卡片：默认精简 + 3 秒预览；可选完整/精简/静默、流式预览、经典/富卡片和进度样式。修复 ACP 思考被重复映射成正文的问题；旧配置和凭据无损迁移。
  • 可靠状态与安全边界：捆绑 cc-connect 提供真实长连接健康信号，分别显示服务启动、飞书通道在线和 DSH 实际任务成功；缺模型 key 指向 Models。Secret 不回读、不进入 TOML/日志；Safe Mode 暂停和持久关闭保持独立。

v0.2.1-alpha.2.shell.0 （内核 0.2.1-alpha.2）

  • 飞书消息连接：从原生「扩展 / Desktop tools」菜单打开独立二维码配置窗口，完成回调后由受监督的 cc-connect Sidecar 将飞书消息接入 DSH；设置页支持启动、停止、重连和 Safe Mode 生命周期。
  • 一键 CLI 与 skills：新增 pnpm run feishu:setup，调用官方 Lark CLI 完成用户 OAuth，并可安装官方 lark-* skills；用户 CLI 身份与 cc-connect 机器人身份明确分离。
  • 运行时与可靠性：升级内置 DSH 到 0.2.1-alpha.2，同步 32 个 peer pin，并按新内核重建登录自动打开补丁；新增多运行时管理面板及更严格的运行时路径校验。
  • 安全边界：二维码配置使用临时目录，Secret 只进入受保护凭证存储或权限为 0600 的文件，不写入日志、仓库或普通设置文件。

v0.2.1-alpha.1.shell.5 （内核 0.2.1-alpha.1）

  • 飞书一键连接：原生扩展菜单提供独立的“配置飞书机器人”二维码流程，选择工作区、扫码确认后自动保存受保护凭证并尝试启动 cc-connect。
  • 官方 Feishu skills：新增 pnpm run feishu:setup，通过官方 @larksuite/cli 安装 lark-* skills 并完成用户 OAuth；用户 CLI 身份与 cc-connect 机器人身份保持分离。
  • 安全边界：二维码流程只使用临时配置目录，App Secret 不进入窗口、配置 TOML、状态、日志或仓库；退出、取消和超时都会清理临时数据。

v0.2.1-alpha.1.shell.4 （内核 0.2.1-alpha.1）

  • 局域网配对稳定性：发布当前主线已实现的多网卡 URL 校验与网卡选择持久化，避免配对二维码锚定回环地址后失败。
  • 故障恢复：发布当前主线已实现的 Windows 运行文件、sharp 原生模块和插件内核不匹配诊断；Safe Mode/插件恢复路径保持可用。
  • 发布链路：移除会触发已知失效 GitCode v5 回补的自动步骤，改由 GitCode v2 国内镜像流程在发布后逐资产匿名校验。
  • 供应链安全：将 sharp 提升到 0.35.5，修复 GHSA-wq5f-xc86-pv6w；sprintf-js 的 CVE-2026-97058 目前无上游修复，审计仅对这一条公告做了显式临时忽略。
  • cc-connect × DSH Desktop：安装包携带受主进程监管的 cc-connect Sidecar，设置页支持飞书凭证、工作区、启动/停止/重连和 Safe Mode 生命周期；Secret 不写入 TOML，用户文档补充了飞书后台要求、脱敏日志和凭证清理步骤。
  • 边界说明：内置官方 Harness 内核版本不变；不新增权限，不改变用户数据目录或垃圾桶保留规则。

v0.2.1-alpha.1.shell.3 （内核 0.2.1-alpha.1）

  • 内核升级：从 0.2.0-rc.2 升级到 0.2.1-alpha.1，同步桌面壳的插件兼容版本与随包依赖。
  • 局域网配对：记住用户选择的网络地址；多网卡环境中先核对二维码所指向的地址，避免二维码指向不可用网卡。
  • 桌面垃圾桶：卡片、操作按钮和页签与设置页视觉风格一致；中文界面按中文格式显示日期，运行中的会话被拒绝删除时显示正确原因。
  • Windows 发布门禁：每个 NSIS 残留场景验证后停止 dsh-desktop 进程族并运行对应卸载器，清除注册安装路径，避免下一场景的旧版静默安装器阻塞。
  • 数据边界：不新增权限，不改变用户数据目录或垃圾桶的 30 天保留规则。
